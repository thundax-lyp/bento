# 三账号远端验收

2026-11-09 在 Bento 主线 `7b93a5f` 上验收 One 和 Two。两轮均使用真实 OpenShell 和 DeepSeek 官方 API 的 `deepseek-v4-flash`，共 6 次模型工具选择调用，均返回 HTTP 200。环境为单控制器、单执行宿主，命令隔离为 `partial`。

## 故障与恢复

三个测试账号分别导入两文件文本快照。首个账号从 Chromium 提交一次任务，另外两个账号通过 One HTTP 提交并进入排队。

宿主独立确认文件修改已经落盘、工具回执尚未写入后，向 worker 发送 SIGKILL。关页重开后，页面找回原 Run 并显示 `needs_review`。接管保留原 Session、Workspace 和历史前缀。旧代 SDK 执行、操作登记和会话持久化请求均被拒，`TOOL_OUTCOME_UNKNOWN` 保留，原 prompt 与工具调用均未重放。

待核对时 diff 不可下载。整卷哈希不匹配的核对请求被拒，可信侧正确核对后，页面成功下载 diff。另外两个排队任务正常完成并交付 diff。

## 三账号浏览器交付

三个独立 Chromium 会话分别登录、导入各自的两文件 UTF-8 项目、提交一次受控 README 编辑任务。关页重开后，三个账号都找回原 Run，并下载与页面预览一致的 diff。独立应用补丁确认 README 只追加一行，另一文件逐字节一致。18 次跨账号读取 Project、Run 和 diff 的尝试均返回 404。
