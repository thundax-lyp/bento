## 物理停写候选复验

2026-11-26 在同一独占沙盒和候选镜像复跑脱离会话的用例。可信侧按完整 Docker 容器 ID 操作，并按 Gateway 命名空间、容器角色与专属卷核对归属。

1. 独立确认原子进程已启动、准备写卷，再暂停原沙盒容器并回读 `Paused=true`。
2. 只在暂停已观测后发起旧代撤权。持有流关闭，旧授权重连返回 gRPC 16。故意延迟物理停止，等过子进程的预定写入时点，再从独立只读挂载读取同一卷。就绪及正对照文件仍在，延迟写入文件不存在。
3. 对仍暂停的同一个完整容器 ID 发送 SIGKILL，回读容器已退出，再由 Gateway 确认沙盒为 Stopped。Docker 复查专属卷无运行中的附件。探针文件已清理。

**未覆盖**：本轮由外部探针在撤权前暂停容器，尚未接入生产的失联、超时、取消、接管和 Session 撤权路径。生产接线须将物理停写绑定到原代的不可变容器 ID，并在暂停确认、撤权和物理停止之间发生控制器重启时继续对账原实例。停止确认和槽位释放继续依赖双侧证明。A3-04 保持「部分实现」。
