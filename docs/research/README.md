架构基线：一顶层业务 Session 一沙盒、Run 调度、共享 worker 池；Workspace 持有持久 Volume，多个 Session 可以共享挂载。优先固定 npm 插件和 OpenShell/DSH 已有扩展，平台补绑定、授权、持久接管和调度；暂无必须修改 DSH 核心的证据。

已跑通跨主机 Session 恢复、持久卷重建、UNKNOWN 不盲重放、旧代拒写及服务端 generation/READY 准入。当前 confinement=partial、单执行宿主；动态身份、最终入口全链故障、多控制器和 HA 等仍需实现验收。

原始证据受控保存、仅用于追溯；[通用部署说明](../deployments/openshell-dsh.md)记录部署机制与运维检查要求。公开材料仅包含结论与适用边界；原始测试脚本、日志、数据库和哈希清单不在公开范围。
